One room, two views

The same session. Two different jobs.

Both roles enter one room, keyed by the session link. The teacher hosts and reviews. The student joins and participates. Neither sees the other's screen.

Teacher view

The room's state, one student at a time. No video wall.

  • Live states, flags and a quiet priority list.
  • Nudge, message, mark engaged, ignore or remove.
  • The session record and PDF after class.

  • Join with the link, complete readiness, enter.

  • Receive a nudge and time to recover.
What each side can do

Both roles find themselves.

The teacher is not an administrator, and the student is not a data point. Each door opens onto a different set of actions, on the same session.

Teacher

  • Host a class and share one session link.
  • See states, flags, NO_DATA and identity checks.
  • Nudge, message, mark engaged, ignore or remove.
  • Review the TPI, timeline and at-risk list after class.
No student score decides anything. TPI is a session-level index for the teacher, computed after class — not a grade, not a ranking.

Student

  • Join with the link and complete a quick readiness check.
  • See your own state; never the class's scores.
  • Receive a private nudge, with time to return.
  • Answer an identity liveness action in 3–5 seconds.
The nudge is not a punishment. It is an invitation back. The teacher sees that it was sent, not what you read.
The rule that keeps it fair

Student first. Teacher last word.

The system points at a person, not a verdict. The student gets the first move and time to recover. The teacher decides what happens next — including nothing.

“A flag is a reason to look, not a reason to punish.”
  1. 01
    A state changes.

    Attentive, distracted, away, disengaged, identity check or NO_DATA.

  2. 02
    The student is nudged.

    A private message and time to recover. No public callout, no grade.

  3. 03
    A liveness action, if needed.

    Turn your head, smile — a 3–5 second window to answer an identity check.

  4. 04
    The teacher decides.

    Mark engaged, message, ignore or remove. Nothing is automated.

No automated discipline · No emotion recognition · Not proctoring

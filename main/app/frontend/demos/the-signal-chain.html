The boundary, in plain words

Small on purpose.

“Nothing is stored” would be false. The honest version is narrower: a face embedding and the session's analytics are stored; the raw material is discarded as it is read.

Crosses the boundary

  • A face embedding, used to check identity consistency when the student returns.
  • Session analytics: scores over time, states, strikes, flags and the final report.
  • Teacher actions: the nudge, the message, the mark, the removal.

Never crosses

  • Video frames. The model reads them in memory and drops them.
  • Page content, app content or the student's screen.
  • Emotion labels, grades, rankings or an automated decision about a student.

Why run it here

Three reasons, no magic.

Client-side inference is an engineering decision with consequences a teacher and a student can feel. It is not a slogan.

01 / LATENCY

The state is current.

A frame is read where it is captured. The student's state changes on the same device that sees the face, without a round trip.

02 / CONSENT

The raw material is never kept.

There is no server-side video archive to lose, leak or subpoena. The frame exists for the length of the inference and then it is gone.

03 / HONESTY

The limits are visible.

The same diagram shows what is stored. The report says NO_DATA when the camera misses, instead of calling it disengagement.

At the other end

The signal points. The teacher decides.

The chain ends with a person, not an action. A flag is a reason to look, not a reason to punish. The student gets the first move and time to recover.

What the teacher can do.

The live board shows states, not a feed. When a student is flagged, the teacher can act — or deliberately do nothing.

  • Nudge the student, with time to return.
  • Mark engaged, message, ignore or remove.
  • Ask for a liveness action — turn head, smile — in a 3–5 second window.
  • Read the record after class and export it as a PDF.

What this is not

The refusals are part of the design.

A system that watches a room owes the room a clear account of what it will not do. These are not caveats buried in a policy.

Not proctoring

Chronos does not lock a browser, block apps, or produce a cheating verdict. Strict mode notices tab focus; it does not police it.

Not emotion recognition

Gaze, head pose and eye openness are geometry. The system does not name a feeling, a mood or a diagnosis.

Not attendance

A face in frame is not a register. Presence is a signal for the session, not an official record.

No automated discipline

No score changes a grade. No flag removes a student. The teacher has the last word, every time.
